Question 1: The difference between Git and GitHub is that Git is a version control system that works locally while GitHub stores Git repositories and allows multiple people to work on the same code base
Question 2: ‘git add <file>’ adds a specific file based on the file name you gave, ‘git add .’ adds all new changes in the current directory, and ‘git add -A’ adds all new changes everywhere
Question 3: git push uploads the changes from the local branch to the remote repository on GitHub. While, git pull takes the changes from the remote repository and merges into the local branch
